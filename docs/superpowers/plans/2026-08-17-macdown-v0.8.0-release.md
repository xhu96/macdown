# MacDown v0.8.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, and publish MacDown `v0.8.0` with GitHub-generated source archives and an explicitly unsigned/not-notarized universal DMG.

**Architecture:** Keep the tagged source tree unchanged at master commit `9aba4a40f60c023e3375ad9c7337de5ffaa6005d`. Use an isolated `codex/release-v0.8.0` branch for two path-triggered workflows: one builds and uploads a verified DMG artifact, and a second downloads that exact successful artifact and publishes the release only after local inspection.

**Tech Stack:** GitHub Actions, Xcode/xcodebuild, CocoaPods/Bundler, Swift Package Manager, Dart Sass, `codesign`, `lipo`, `hdiutil`, GitHub CLI.

## Global Constraints

- Release version and tag are exactly `0.8.0` and `v0.8.0`.
- Release target is exactly `9aba4a40f60c023e3375ad9c7337de5ffaa6005d`.
- DMG filename is exactly `MacDown-0.8.0-unsigned.dmg`.
- The app is ad-hoc signed only; it is not Developer ID signed or notarized.
- The app must contain `arm64` and `x86_64` slices and target macOS 11.0 or later.
- Do not create the tag or release until the build artifact passes both workflow and local verification.
- Do not merge the technical workflow branch into `master`.

### Task 1: Build and package the unsigned universal application

**Files:**
- Create: `.github/workflows/build-unsigned-v0.8.0.yml`

**Interfaces:**
- Consumes: the project at release commit `9aba4a40f60c023e3375ad9c7337de5ffaa6005d` plus the isolated branch workflow commit.
- Produces: GitHub Actions artifact `MacDown-0.8.0-unsigned` containing `MacDown-0.8.0-unsigned.dmg`, `MacDown-0.8.0-unsigned.dmg.sha256`, and `verification.txt`.

- [ ] **Step 1: Add the path-triggered build workflow**

```yaml
name: Build unsigned v0.8.0 DMG

on:
  push:
    branches:
      - codex/release-v0.8.0
    paths:
      - .github/workflows/build-unsigned-v0.8.0.yml

permissions:
  contents: read

concurrency:
  group: macdown-v0.8.0-unsigned-build
  cancel-in-progress: false

jobs:
  build:
    runs-on: macos-15
    timeout-minutes: 60
    env:
      RELEASE_VERSION: 0.8.0
      RELEASE_BUILD: 1118
      DMG_NAME: MacDown-0.8.0-unsigned.dmg
      ARCHIVE_PATH: ${{ runner.temp }}/MacDown.xcarchive
      DIST_DIR: ${{ runner.temp }}/dist

    steps:
      - name: Check out source and submodules
        uses: actions/checkout@v4
        with:
          submodules: recursive

      - name: Select Ruby and install bundled gems
        uses: ruby/setup-ruby@v1
        with:
          ruby-version: "3.3"
          bundler-cache: true

      - name: Report build environment
        run: |
          set -euo pipefail
          uname -a
          xcodebuild -version
          ruby --version
          bundle --version
          node --version
          npm --version

      - name: Install CocoaPods dependencies
        run: |
          set -euo pipefail
          bundle exec pod install

      - name: Build parser dependency
        run: |
          set -euo pipefail
          make -C Dependency/peg-markdown-highlight

      - name: Generate GitHub stylesheet with maintained Sass
        run: |
          set -euo pipefail
          sass_root="$RUNNER_TEMP/macdown-sass"
          mkdir -p "$sass_root"
          npm install --prefix "$sass_root" --no-package-lock --no-save sass@1.77.8 primer-markdown@4.0.0
          "$sass_root/node_modules/.bin/sass" \
            --load-path "$sass_root/node_modules" \
            Tools/GitHub-style-generator/index.sass \
            | sed 's/.markdown-body/body/' \
            > MacDown/Resources/Styles/GitHub-2020.css
          test -s MacDown/Resources/Styles/GitHub-2020.css

      - name: Set release bundle metadata
        run: |
          set -euo pipefail
          plist=MacDown/MacDown-Info.plist
          /usr/libexec/PlistBuddy -c "Set :CFBundleShortVersionString $RELEASE_VERSION" "$plist"
          /usr/libexec/PlistBuddy -c "Set :CFBundleVersion $RELEASE_BUILD" "$plist"
          /usr/libexec/PlistBuddy -c "Add :CFBundleBuildVersion string $GITHUB_SHA" "$plist" 2>/dev/null \
            || /usr/libexec/PlistBuddy -c "Set :CFBundleBuildVersion $GITHUB_SHA" "$plist"

      - name: Archive universal Release build with ad-hoc signing
        run: |
          set -euo pipefail
          xcodebuild archive \
            -workspace MacDown.xcworkspace \
            -scheme MacDown \
            -configuration Release \
            -destination 'generic/platform=macOS' \
            -archivePath "$ARCHIVE_PATH" \
            ARCHS='arm64 x86_64' \
            ONLY_ACTIVE_ARCH=NO \
            CODE_SIGN_IDENTITY='-' \
            CODE_SIGNING_REQUIRED=YES

      - name: Verify application bundle
        run: |
          set -euo pipefail
          app="$ARCHIVE_PATH/Products/Applications/MacDown.app"
          executable="$app/Contents/MacOS/MacDown"
          info="$app/Contents/Info.plist"
          test -d "$app"
          codesign --verify --deep --strict --verbose=4 "$app"
          version="$(plutil -extract CFBundleShortVersionString raw -o - "$info")"
          test "$version" = "$RELEASE_VERSION"
          deployment="$(otool -l "$executable" | awk '/LC_BUILD_VERSION/{found=1} found && /minos/{print $2; exit}')"
          test "$deployment" = "11.0"
          archs="$(lipo -archs "$executable")"
          case " $archs " in *' arm64 '*) ;; *) exit 1 ;; esac
          case " $archs " in *' x86_64 '*) ;; *) exit 1 ;; esac
          {
            echo "version=$version"
            echo "build=$(plutil -extract CFBundleVersion raw -o - "$info")"
            echo "deployment_target=$deployment"
            echo "architectures=$archs"
            codesign -dvvv "$app" 2>&1
          } | tee "$RUNNER_TEMP/verification.txt"

      - name: Create and verify DMG
        run: |
          set -euo pipefail
          app="$ARCHIVE_PATH/Products/Applications/MacDown.app"
          stage="$RUNNER_TEMP/dmg-root"
          mount="$RUNNER_TEMP/dmg-mount"
          mkdir -p "$stage" "$mount" "$DIST_DIR"
          ditto "$app" "$stage/MacDown.app"
          ln -s /Applications "$stage/Applications"
          hdiutil create \
            -volname "MacDown $RELEASE_VERSION" \
            -srcfolder "$stage" \
            -format UDZO \
            -ov \
            "$DIST_DIR/$DMG_NAME"
          hdiutil verify "$DIST_DIR/$DMG_NAME"
          device="$(hdiutil attach "$DIST_DIR/$DMG_NAME" -nobrowse -readonly -mountpoint "$mount" | awk '/^\/dev\//{print $1; exit}')"
          cleanup() { hdiutil detach "$device" || true; }
          trap cleanup EXIT
          test -d "$mount/MacDown.app"
          test -L "$mount/Applications"
          codesign --verify --deep --strict --verbose=4 "$mount/MacDown.app"
          test "$(plutil -extract CFBundleShortVersionString raw -o - "$mount/MacDown.app/Contents/Info.plist")" = "$RELEASE_VERSION"
          mounted_archs="$(lipo -archs "$mount/MacDown.app/Contents/MacOS/MacDown")"
          case " $mounted_archs " in *' arm64 '*) ;; *) exit 1 ;; esac
          case " $mounted_archs " in *' x86_64 '*) ;; *) exit 1 ;; esac
          hdiutil detach "$device"
          trap - EXIT
          (cd "$DIST_DIR" && shasum -a 256 "$DMG_NAME" > "$DMG_NAME.sha256")
          cp "$RUNNER_TEMP/verification.txt" "$DIST_DIR/verification.txt"

      - name: Upload verified release candidate
        uses: actions/upload-artifact@v4
        with:
          name: MacDown-0.8.0-unsigned
          path: ${{ runner.temp }}/dist/*
          if-no-files-found: error
          retention-days: 30
```

### Task 3: Publish the verified artifact as GitHub Release v0.8.0

**Files:**
- Create: `.github/workflows/publish-unsigned-v0.8.0.yml`

**Interfaces:**
- Consumes: latest successful `Build unsigned v0.8.0 DMG` artifact from the unchanged technical branch, already verified locally in Task 2.
- Produces: tag `v0.8.0` at the release commit and a public GitHub Release with DMG and checksum assets.

- [ ] **Step 1: Add the one-purpose publishing workflow**

```yaml
name: Publish v0.8.0

on:
  push:
    branches:
      - codex/release-v0.8.0
    paths:
      - .github/workflows/publish-unsigned-v0.8.0.yml

permissions:
  actions: read
  contents: write

jobs:
  publish:
    runs-on: ubuntu-24.04
    timeout-minutes: 15
    env:
      GH_TOKEN: ${{ github.token }}
      RELEASE_TAG: v0.8.0
      RELEASE_COMMIT: 9aba4a40f60c023e3375ad9c7337de5ffaa6005d
      BUILD_WORKFLOW: build-unsigned-v0.8.0.yml
      ARTIFACT_NAME: MacDown-0.8.0-unsigned
      DMG_NAME: MacDown-0.8.0-unsigned.dmg

    steps:
      - name: Refuse to overwrite an existing tag or release
        run: |
          set -euo pipefail
          if gh api "repos/$GITHUB_REPOSITORY/git/ref/tags/$RELEASE_TAG" >/dev/null 2>&1; then
            echo "Tag $RELEASE_TAG already exists" >&2
            exit 1
          fi
          if gh release view "$RELEASE_TAG" --repo "$GITHUB_REPOSITORY" >/dev/null 2>&1; then
            echo "Release $RELEASE_TAG already exists" >&2
            exit 1
          fi

      - name: Download the latest successful verified build artifact
        run: |
          set -euo pipefail
          run_id="$(gh run list \
            --repo "$GITHUB_REPOSITORY" \
            --workflow "$BUILD_WORKFLOW" \
            --branch codex/release-v0.8.0 \
            --status success \
            --limit 1 \
            --json databaseId \
            --jq '.[0].databaseId')"
          test -n "$run_id"
          mkdir -p dist
          gh run download "$run_id" \
            --repo "$GITHUB_REPOSITORY" \
            --name "$ARTIFACT_NAME" \
            --dir dist

      - name: Verify release files and source target
        run: |
          set -euo pipefail
          test -f "dist/$DMG_NAME"
          test -f "dist/$DMG_NAME.sha256"
          (cd dist && sha256sum -c "$DMG_NAME.sha256")
          target="$(gh api "repos/$GITHUB_REPOSITORY/commits/$RELEASE_COMMIT" --jq .sha)"
          test "$target" = "$RELEASE_COMMIT"

      - name: Write release notes
        run: |
          cat > release-notes.md <<'NOTES'
          ## MacDown 0.8.0

          This is the first release of the modernized MacDown fork for macOS 11 and later.

          Highlights:

          - Universal Apple Silicon and Intel application (`arm64` and `x86_64`).
          - Updated project settings for modern macOS SDKs and Xcode.
          - Sparkle 2 integration, with automatic updates disabled until an appcast and public key are configured.
          - Restored rendering preferences layout and removed stale terminal preference outlets.
          - Albanian localization.
          - CocoaPods dependency refresh.

          ### Important security notice

          `MacDown-0.8.0-unsigned.dmg` is ad-hoc signed only. It is **not** signed with an Apple Developer ID and is **not notarized by Apple**. macOS Gatekeeper may prevent a normal double-click launch. Only download and open it if you trust this repository and understand that limitation.

          Source commit: `9aba4a40f60c023e3375ad9c7337de5ffaa6005d`.

          GitHub provides the source code ZIP and tarball automatically below. The attached SHA-256 file verifies the DMG download.
          NOTES

      - name: Create tag and publish release with verified assets
        run: |
          set -euo pipefail
          gh release create "$RELEASE_TAG" \
            "dist/$DMG_NAME" \
            "dist/$DMG_NAME.sha256" \
            --repo "$GITHUB_REPOSITORY" \
            --target "$RELEASE_COMMIT" \
            --title "MacDown 0.8.0" \
            --notes-file release-notes.md \
            --latest
```
